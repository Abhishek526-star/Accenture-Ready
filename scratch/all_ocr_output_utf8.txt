[slide_18_image49.png] The primary function of DNS (Domain Name System) is to translate human-readable domain names (like 'vuw.example.com') into IP addresses (like '192.168.1.1') that computers use to identify each other on the network. This process is crucial because while humans find it easier to remember domain names, computers need IP addresses to route data to the correct destination on the internet or a local network. Essentially, DNS acts as a directory that matches domain names with their corresponding IP addresses.
[slide_18_image48.png] The Transport layer (Layer 4) of the OSI model is responsible for ensuring that the entire message arrives at its destination without errors. It does this by using error detection and correction mechanisms, such as checksums. If an error is detected, the Transport layer can request the retransmission of the affected data segments, ensuring reliable communication between the sender and receiver. In particular, protocols like TCP (Transmission Control Protocol) operate at this layer to provide this reliability.

[slide_33_image87.png] Private IP addresses A private IP address, also called a local IP address, is the IP address used to identify each device within your local network. While your public IP address is visible to devices outside your network, your private IP address is only visible within your network. Each device within your network requires its own unique private IP address so your router can easily direct traffic to the correct device, since even a home network is likely to host multiple devices—laptops, smartphones, printers, speakers, tablets, etc.
[slide_33_image86.png] IP subnetting, or subnetting, is the process of dividing a large network into smaller, more manageable subnetworks. It has several purposes, including: Improved network performance Subnetting can reduce network traffic and improve network performance by sorting and routing packets by subnet. Enhanced network security Subnetting can help limit network breaches by isolating compromised subnetworks. Simplified network management Subnetting can help prevent the wastage of IP addresses and make it easier to communicate between subnetworks. Accommodating network growth Subnetting can help accommodate network expansion and increase network scalability.
